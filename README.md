# Second Skin Wraps — Website Concept

Website mockup for a fictional vinyl wrap shop in Austin, TX. A print-shop proof sheet whose accent colour is whatever vinyl you pick, plus a film-length estimator.

**Live:** https://thinkfirstjason.github.io/second-skin-wraps/

- Single static `index.html`, no build step
- Design language for reuse: [DESIGN.md](DESIGN.md)
- Photos from [Unsplash](https://unsplash.com) (Unsplash License)

Fictional business. Names, addresses and phone numbers are made up.
